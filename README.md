# CircuitLab Studio

**CircuitLab Studio** is a professional, browser-based SPICE electronic circuit simulator featuring a real-time Modified Nodal Analysis (MNA) solver, interactive schematic capture, orthogonal wire routing, real-time component health telemetry, dual-channel digital oscilloscope, and DC motor simulation with back-EMF feedback.

## Features
- **Real-Time MNA SPICE Engine**: Gaussian elimination solver with passive and active component stamping.
- **DC Motor Simulation**: Dynamic armature rotation whose RPM scales with applied terminal voltage, feeding back back-EMF into the solver.
- **Component Health & Overload Protection**: Live monitoring of voltage drops, current flow, and power dissipation with automated burnout fault detection.
- **Dual-Channel Digital Oscilloscope**: Real-time waveform tracing for node voltages and component currents.
- **Preset Circuits**: Built-in templates for RC Filters, Motor Driver Circuits, and Boost Converters.

## Getting Started
Simply open `index.html` in any modern web browser or host it via GitHub Pages.
